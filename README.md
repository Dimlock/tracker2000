# 2000 дней · Генератор бумажного трекера

Однофайловое веб-приложение для создания печатных шаблонов бумажного трекера на **2000 дней**: A5-папка на кольцах, 20 блоков по 100 дней, 66–67 месячных страниц, жетоны пропусков, карточки ритуалов и система возвращения после пропусков.

Приложение рассчитывает все даты от выбранного дня старта, показывает страницы в реальном масштабе A5 и позволяет напечатать весь комплект или только текущий отрезок.

## Быстрый старт

1. Откройте `index.html` в браузере.
2. В левой панели задайте:
   - название трекера;
   - практику;
   - дату старта;
   - якорь ритуала;
   - минимальный день.
3. При необходимости измените награды за вехи и оформление.
4. Выберите пресет комплекта:
   - **Стартовый набор** — для запуска;
   - **Только текущее** — для ежедневной поддержки;
   - **Всё · 2000 дней** — для полного архива;
   - **Очистить** — для ручной сборки комплекта.
5. Проверьте страницы во вкладках предпросмотра.
6. Нажмите **Печать / PDF**.
7. В диалоге печати выберите принтер или сохранение в PDF.
8. Напечатайте, разрежьте карточки и жетоны, соберите папку.

Сборка не требует терминала, npm, сервера или внешних JavaScript-библиотек.

## Как работает расчёт дат

Дата старта считается **днём 1**.

```text
День 1    = дата старта
День 100  = дата старта + 99 дней
День 2000 = дата старта + 1999 дней
```

Блоки:

```text
Блок 1  → дни 1–100
Блок 2  → дни 101–200
Блок 3  → дни 201–300
...
Блок 20 → дни 1901–2000
```

Месячные страницы создаются от месяца старта до месяца финиша включительно. Первый и последний месяц могут быть неполными — приложение учитывает только дни, входящие в диапазон 1–2000.

В месячной сетке:

- неделя начинается с понедельника;
- дни вне текущего месяца показываются штриховкой;
- дни вне диапазона трекера перечёркиваются;
- внутри диапазона отображается номер дня трекера;
- сегодняшний день может быть выделен акцентной рамкой.

Даты рассчитываются в локальном часовом поясе браузера.

## Настройка оформления

### Цвета

Доступны два независимых цвета:

- **Цвет чернил** — основной текст, сетки и символы.
- **Акцент** — штампы, вехи, текущий день, декоративные элементы и жетоны.

Для каждого цвета есть готовые варианты и собственный выбор цвета.

Рекомендуется использовать не более двух цветов: так комплект проще печатать и поддерживать.

### Заголовки

Доступны три стиля:

- **Классика · serif**;
- **Гротеск**;
- **Технический · mono**.

### Линии сетки

Доступны три варианта:

- тонкие сплошные линии;
- пунктир;
- точки.

### Клетка 100-дневного листа

Размер клетки регулируется в диапазоне:

```text
10–12,5 мм
```

Значение по умолчанию:

```text
12 мм
```

Сетка 10 × 10 остаётся совместимой с форматом A5 при любом значении из этого диапазона.

## Форматы печати

### A5

Основной формат приложения.

```text
148 × 210 мм
```

Страницы печатаются напрямую на бумаге A5.

### A4 с метками реза

Если принтер не поддерживает A5, выберите A4.

```text
210 × 297 мм
```

Каждая A5-страница размещается по центру A4-листа и получает метки реза. После печати лист разрезается до формата A5.

## Настройки диалога печати

Для корректного результата используйте следующие параметры:

| Параметр | Значение |
|---|---|
| Масштаб | 100 % |
| Режим масштаба | Реальный размер / Actual size |
| Поля | Нет / None |
| Фоновая графика | Включена |
| Колонтитулы | Выключены |
| Размер бумаги | A5 или A4 — в зависимости от выбранного формата |
| Ориентация | Книжная |
| Двусторонняя печать | По желанию |

Не используйте режим «По размеру страницы» или «Fit to page»: он может уменьшить сетку и нарушить размеры клеток.

Перед печатью полного комплекта рекомендуется напечатать одну страницу и проверить линейкой размер клетки.

## Сохранение в PDF

1. Соберите нужный комплект.
2. Нажмите **Печать / PDF**.
3. В качестве принтера выберите **Сохранить как PDF**.
4. Проверьте формат бумаги:
   - A5;
   - или A4, если выбран режим с метками реза.
5. Установите масштаб 100 %.
6. Отключите колонтитулы.
7. Включите фоновую графику.
8. Сохраните файл.

PDF можно хранить как резервную копию комплекта или отправлять в копицентр.

- лист жетонов на восемь отдельных жетонов;

## Ручной выбор страниц

В разделе **Комплект печати** можно включить или выключить любой тип страниц.

Для 100-дневных листов доступны режимы:

- только текущий блок;
- все 20 блоков;
- произвольный диапазон.

Для месячных страниц доступны режимы:

- только текущий месяц;
- текущий и следующий месяц;
- все месяцы;
- произвольный диапазон.

Месяцы нумеруются от старта трекера:

```text
1 = первый месяц трекера
66 или 67 = последний месяц трекера
```

Под диапазонами показывается соответствие номеров реальным месяцам.

Счётчик страниц обновляется сразу после изменения выбора.

## Управление

### Вкладки страниц

Верхняя панель предпросмотра содержит все типы страниц:

```text
Обложка
Если — то
Правила
Карта этапов
Легенда
100-дневный лист
Месяцы
Вехи
Жетоны
Карточки
Обзор недели
Разделители
Протокол
Сборка
Чек-лист
```

Вкладки прокручиваются горизонтально, если не помещаются по ширине.

### Навигация внутри типа

Для блоков, месяцев и разделителей доступны:

- предыдущая страница;
- следующая страница;
- выпадающий список;
- кнопка «К текущему».

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `←` | Предыдущая страница внутри текущего типа |
| `→` | Следующая страница внутри текущего типа |
| `Ctrl + P` / `Cmd + P` | Открыть системную печать |

Стрелки не перехватываются, если фокус находится в поле ввода.

Если комплект пуст, системная печать использует текущую страницу предпросмотра.

### Масштаб предпросмотра

| Элемент | Действие |
|---|---|
| `−` | Уменьшить |
| `+` | Увеличить |
| `Вписать` | Вернуть масштаб по размеру области |
| Проценты | Текущий масштаб предпросмотра |

Масштаб предпросмотра не влияет на размер печати.

## Звук

Интерфейс использует короткие синтезированные звуки:

- тихий щелчок при изменении настроек;
- шелест при переключении страниц;
- мягкий удар штампа при выборе комплекта и печати.

Звуки создаются через Web Audio API и не требуют аудиофайлов.

Кнопка **Звук вкл / Звук выкл** находится в верхней панели и отключает все звуки одним действием.

## Экспорт и импорт настроек

### Экспорт

Кнопка **.json** скачивает файл с текущими настройками.

Формат имени:

```text
tracker-2000-YYYY-MM-DD.json
```

Файл можно использовать для:

- резервной копии;
- переноса между браузерами;
- переноса между устройствами;
- создания отдельных комплектов для разных привычек.

### Импорт

Кнопка **Открыть** загружает ранее сохранённый JSON-файл.

После импорта настройки сразу применяются ко всем шаблонам и комплекту печати.

Перед импортом сохраняется состояние для отмены.

## Сброс и случайное оформление

### Сброс

Кнопка **Сброс** возвращает исходные значения:

- дату старта на сегодня;
- название по умолчанию;
- практику по умолчанию;
- стандартный якорь;
- стандартный минимальный день;
- три жетона в месяц;
- исходные награды;
- графитовые чернила;
- вермилионовый акцент;
- serif-заголовки;
- сплошную сетку;
- клетку 12 мм;
- формат A5;
- стартовый комплект.

Перед сбросом сохраняется состояние для отмены.

### Случайное оформление

Кнопка **Стиль** случайным образом выбирает:

- цвет чернил;
- акцентный цвет;
- стиль заголовков;
- стиль линий сетки;
- размер клетки.

Тексты, даты, награды и состав комплекта не изменяются.

## Адаптивность

### Широкий экран

Интерфейс разделён на две области:

- слева — постоянная панель управления;
- справа — вкладки, предпросмотр и печать.

### Узкий экран

Предпросмотр располагается сверху, настройки — ниже. Основные действия остаются доступными через верхнюю панель.

### Маленький экран

Шапка становится компактнее, второстепенные подписи скрываются, вкладки прокручиваются горизонтально.

Для печати полного комплекта рекомендуется использовать компьютер или ноутбук: так проще проверить состав, диапазоны и настройки драйвера принтера.

- Нет серверной части.
- Нет аккаунтов и регистрации.
- Нет аналитики.
- Размеры шаблонов заданы в миллиметрах и пунктах.
- Предпросмотр использует тот же HTML и CSS, что и печать.
- Для печати применяются правила `@page`.
- Форматы страниц:
  - A5: `148mm × 210mm`;
  - A4: `210mm × 297mm`.
- Для сохранения цветов используется `print-color-adjust: exact`.
- Символы трекера нарисованы как SVG и не зависят от наличия специальных глифов в шрифте.
- Метки реза строятся автоматически для режима A4.
- Звук синтезируется через Web Audio API.
- Для обновления статуса текущего дня используется периодическая проверка даты.
- Учитывается системная настройка уменьшения движения.

## Шрифты

Приложение использует Google Fonts:

- **Unbounded** — логотип и крупные числа;
- **Golos Text** — интерфейс;
- **PT Serif** — классические заголовки шаблонов;
- **PT Sans** — основной текст шаблонов;
- **PT Mono** — даты, номера и технические подписи.

Если шрифты недоступны, используются системные запасные варианты. Приложение продолжает работать, но типографика может отличаться.

Для полностью автономной работы можно заменить подключение Google Fonts локальными файлами шрифтов.

## Приватность

Приложение работает локально в браузере.

Оно не отправляет на сервер:

- название трекера;
- практику;
- даты;
- награды;
- настройки оформления;
- состав комплекта.

Единственный внешний ресурс по умолчанию — Google Fonts.

Экспорт JSON происходит только по явному действию пользователя.

## Частые проблемы

### Цвета или фон не печатаются

Включите **Фоновая графика / Background graphics** в диалоге печати.

### Клетки имеют неправильный размер

Проверьте:

- масштаб 100 %;
- отключён режим «По размеру страницы»;
- выбран правильный формат бумаги;
- поля установлены в «Нет»;
- не включены дополнительные колонтитулы.

### Лист A5 печатается слишком маленьким на A4

Выберите в приложении формат **A4 с метками реза**. Тогда страница будет размещена на A4 в правильном размере.

### Кнопка печати неактивна

Комплект пуст. Выберите хотя бы одну страницу или примените пресет.

### Настройки пропали

Возможные причины:

- очищены данные сайта;
- использован другой браузер;
- открыта приватная сессия;
- файл открыт с другим локальным адресом.

Восстановите настройки из экспортированного JSON.

### Шрифты выглядят иначе

Дождитесь загрузки Google Fonts или проверьте подключение к интернету. Без сети приложение использует запасные шрифты.

### Не работает звук

Проверьте:

- включён ли звук в верхней панели;
- не заблокирован ли звук браузером;
- не отключён ли звук системы.

Звук не влияет на генерацию и печать шаблонов.

### Системная печать открывает не тот комплект

Приложение автоматически подставляет выбранный комплект перед печатью. Если комплект пуст, используется текущая страница предпросмотра.

### На телефоне неудобно собирать комплект

Откройте приложение на компьютере. Мобильная версия подходит для просмотра и настройки, но полный комплект удобнее проверять на большом экране.

## Ограничения

- Длина пути фиксирована: **2000 дней**.
- Один комплект предназначен для одной привычки или одной идентичности.
- Для второй привычки рекомендуется отдельный JSON-файл и отдельная папка.
- Приложение генерирует шаблоны, но не ведёт цифровую историю отметок.
- Ежедневные символы ставятся вручную на бумаге.
- Неполные первый и последний месяцы сохраняются как есть.
- Точность физического размера зависит от настроек печати.

## Философия трекера

Семь правил, зашитых в комплект:

1. Пропуск — это данные, а не провал.
2. Никогда не пропускай дважды.
3. Минимальный день считается.
4. Плановый пропуск легален.
5. Возврат важнее streak.
6. Сравнивай только с собой.
7. Награда — за вехи, не за идеальность.

Главная задача комплекта — сделать ежедневную отметку лёгкой, а возвращение после пропуска нормальным.

```text
Один текущий лист.
Один символ.
20 секунд.
Легальные пропуски.
Поощряемый возврат.
```
